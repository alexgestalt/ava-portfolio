Featured project

Ava, AI receptionist & lead‑gen bot

Portfolio demo. Ava works for Cedar & Pine Dental, a fictional dental clinic I made up for this demo. It is not a real business or a client project.

47-second walkthrough of a complete conversation, from first message to booked appointment.

Ava is a website chat assistant for a local service business. She answers common questions, qualifies each visitor, and turns the conversation into a booked appointment request and a clean lead record.

How it works

  1. Qualifies leads. Collects the visitor's name, service need, urgency and contact details, even when they say several things in one message.
  2. Books appointment requests. Offers open time slots based on urgency, then confirms the booking.
  3. Logs every qualified lead. The n8n workflow adds each qualified lead to a Google Sheets spreadsheet.
  4. Alerts the team. It sends a lead summary to the front desk by email or WhatsApp.

The live demo runs entirely in your browser with rule-based logic (no API keys), so anyone can try it. The n8n workflow is the production version, built around an AI agent.

Using the workflow file

In n8n, go to Workflows → Import from File, then connect your own credentials and replace each REPLACE_ME / REPLACE_WITH_* placeholder. The file contains no API keys or personal data.
